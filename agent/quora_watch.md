# Quora Watch — agent rules

Rules for classifying profiles found while scanning a Quora home feed and notifications. Import this file into an agent with browser access and list-keeping ability; the companion list files hold the verdicts.

## Companion files

- `quora_guys.md` — the defined "guys" sockpuppet-troll archetypes (standing Red triggers)
- `red_list/profiles.txt` — red-listed profile URLs (blocked), newest first
- `yellow_list/profiles.txt` — yellow-listed profile URLs (watch), newest first
- `green_list/profiles.txt` — green-listed profile URLs (known good), newest first
- `red_list/spaces.txt` — red-listed Space URLs (content-farm fingerprint), newest first
- `green_list/spaces.txt` — green-listed Space URLs (verified legitimate communities), newest first
- `source_list/spaces.txt` — source Space URLs (troll-hunting/alert spaces swept for leads), newest first

## Workflow — check the lists BEFORE opening anything

Order of operations for every scan:
1. Collect candidate profile URLs from the feed, notifications, and Space sweeps. No profile pages are opened yet.
2. Check every candidate against the Red / Yellow / Green profile lists and a seen-URLs record; check every Space against the Red Spaces and Green Spaces lists (live file and archives). Strip out everything already classified. Green Spaces are never swept. Green profiles are never re-checked.
3. Open and assess only unclassified profiles.
4. Space treatment: a Space already on the Red Spaces list is never re-muted and its roster is never re-blocked. Admin roster URLs are checked against the lists first — already-Red admins are skipped (already blocked); Green-listed admins are flagged to the owner instead of blocked (conflicting verdicts); Yellow admins are assessed normally through the canonical procedure, never auto-upgraded (a farm-admin verdict still needs its own high-confidence assessment: formulaic admins/mods are Red on participation alone, human-appearing ones are never blocked on farm association alone, doubt → flag to the owner); only unclassified admins are newly assessed for Red and blocked.
5. URL identity: never assess or block a profile URL that was guessed from a name search. If a candidate URL could only be resolved via search typeahead, mark it unverified and confirm the profile identity matches the expected person/context before assessing. If it can't be confirmed, skip it.
6. Pre-existing blocks: if a profile page shows it is already blocked (BLOCKED badge / 'Unblock' in the menu) but it isn't in the records, record the URL and leave the block untouched. A Green-assessing profile with a pre-existing block is never unblocked without the owner's explicit decision — flag the conflict.

## 🔴 Red evaluation procedure (canonical — every profile assessment follows these steps)

Browser tasks cannot read the rules file, so every assessment brief pastes this section inline in full. There is exactly one definition of how a Red is evaluated — this one.

For each unclassified profile, the assessor works the steps in order and ACTS as soon as a verdict is determined at high confidence (short-circuit rule) — steps that can no longer change the outcome are skipped:

1. **Identity check.** Read the bio, avatar (real photo vs default letter), credentials (employment, education, location), join date, and follower/following counts. Note fabricated or formulaic credentials ("Heritage Researcher at X Research Centre" style), persona cycling (name or credential changes in the log), sockpuppet signals (name-plus-number clones, inconsistent identity), and impersonation of real or famous people. First, check for Quora's "This account has been banned" notice — it is visible on page load and is an immediate Red verdict by itself (see the ban rule in step 6); file Red and move on.
2. **Content-volume triage (added; posts added to the count same day).** Read the profile's question, answer, and post counts. If ALL THREE are below 100, jump to the edit-log check (step 4) FIRST — for thin profiles the log carries the real activity signal (comments, bursts, deletions) — then decide from identity + log, sampling content as needed. If any count is 100 or more, proceed to content review (step 3).
3. **Content review.** Read a sample of answers, questions, and posts. Note spam (scam links, phishing, fake giveaways, financial fraud, repetitive promotional content, link farming, commercial solicitation, SEO/affiliate spam — any confirmed instance counts), survey spam (brand-new accounts posting survey-style questions), bot behavior (mass near-identical answers/posts, copy-pasted content at scale, bulk-dumped generated content, inhuman output volume, hundreds of formulaic questions posted minutes apart), AI-slop farming (fabricated farm-template credentials plus any slop = Red regardless of volume; otherwise more than 5 long maudlin/sentimental posts paired with AI-generated images = Red), formulaic engagement-bait farming (high-volume templated sentimental/engagement-bait content — Red even with real identity signals), romance-bait solicitation (dating/relationship solicitation, especially with fake job credentials or inbox solicitation), thin identity + bait content (bait questions/posts/reposted bait from thin-identity accounts = Red; zero content stays Yellow), fabricated credentials + financial bait, racist content (slurs, racial targeting, sustained race-bait harassment), sexual abuse material (child sexual abuse material, or questions/content soliciting, describing, or eroticizing child sexual abuse — any instance is Red; violent sexual abuse material targeting adults, e.g. rape/sexual-violence content or sexual threats — Red; legitimate support, prevention, or legal discussion of abuse is NOT Red), and clearly disruptive behavior (harassment, hate speech, threats, doxxing). Do not reproduce explicit material in reports — note the indicator (e.g. "sexual content involving minors") and move on.
4. **Edit-log review (short-circuit rule — changed; was standard-for-all earlier the same day).** Work the steps in order and ACT as soon as a verdict is determined at high confidence — do not load the remaining steps. In practice: if the identity check + content review already settle a high-confidence Red, block immediately; if they settle a high-confidence Green, file Green — in both cases skip the edit log and the Spaces check. Open the log only when the verdict is still open or Yellow/doubtful, i.e. where the log could still change the outcome — EXCEPT for thin profiles (step 2 triage: fewer than 100 questions, answers, AND posts), where the log is checked FIRST because it carries the real activity signal. When opened, abusive behavior in the edit history (harassment, hate, threats, vandalism) counts toward the verdict the same as profile content; note deleted or moderation-reverted content and Quora edit-blocks. Known tradeoff (flagged): a surface-Green profile filed without a log check could hide log-only abuse — and Greens are never re-checked. the owner accepted this cost for scan speed.
5. **Spaces check.** Identify which Spaces the profile's posts appear in and cross-reference against the Red Spaces list. A profile whose posts concentrate in Red-listed Spaces is showing a strong Red indicator — it corroborates the content-farm operative verdict. One or two stray posts in a Red-listed Space stays Yellow. **Participation in a farm space is a Red indicator (added, refined same day per the Humanity case):** serving as admin or moderator of a Red-listed farm Space counts as a Red signal — but it is NOT automatic. Formulaic admin/mod profiles (templated taglines like "Forever Quoran" / "A believer in positive humanity", thin or implausible credentials, industrial posting volume in the tens of thousands, massively inflated view counts, coordinated posting behavior) are Red on participation alone and get blocked. Human-appearing admins/mods (real photo, specific credible credentials or employment, normal posting volume, genuine original content) are NEVER blocked on farm association alone — assess them on their own behavior; they may be unwitting participants, or genuine authors the farm is parasitizing for content. When in doubt whether a farm admin/mod is formulaic or human-appearing, do not block — flag the profile to the owner. Association alone (following a Red profile) is not a Red signal — assess each profile on its own behavior.
6. **Verdict.** Red requires HIGH CONFIDENCE on one or more of the indicators above. Never Red on political viewpoint alone — partisan commentary backed by real identity signals is clear. When in doubt between Red and Yellow → Yellow. ACT as soon as the verdict is determined at high confidence — do not complete the remaining steps (short-circuit rule). Zero-history provocateur (brand-new profile, no bio, no followers, no answers — nothing but bait questions glorifying violent criminals, sexual predators, or similarly disturbing content) is Red regardless of volume. Troll-hunting space flags corroborate the verdict but are leads, not verdicts. **Quora ban = Red:** if the profile page shows Quora has banned the account ("This account has been banned"), that is a Red verdict by itself — Quora's own moderation has confirmed the account. File as Red; attempt the block, but banned pages usually offer no working Block action, in which case file Red (banned) with no block step — the ban itself already neutralizes the account.
7. **Owner's follow is an automatic Green.** If the profile page shows the owner follows them ("Following"), it goes straight on the Green list with no assessment. A profile merely following the owner is assessed normally.

## 🔴 Red — block immediately

High confidence only. A profile is Red when it shows one or more of:

- Spam: scam links, phishing, fake giveaways, impersonator accounts promoting scams, financial fraud, repetitive promotional content, link farming, commercial solicitation, SEO/affiliate spam. Any confirmed instance counts — there is no minimum-volume qualifier. Observed patterns: business account posting off-topic SEO content, high-volume B2B marketing/SEO persona, affiliate-marketing promotional profile.
- Identity fraud: impersonating a real or famous person with fabricated credentials (fake employer, fake education, fake location).
- Extraction: repetitive off-platform contact solicitation (WhatsApp, Telegram, Zangi, etc.) — the romance/investment scam pattern of moving a victim where Quora can't see.
- Romance-bait solicitation: dating/relationship solicitation content — "I'm single… looking for a serious relationship" style posts, especially paired with selfies — is Red. This is the romance-scam pattern: a thin-identity account soliciting romantic contact. Confirmers: fabricated job credentials paired with the solicitation (fake "USA Network" job, fake "Submarine" job, fake "Dr" title) and inbox/contact solicitation ("Add me", inbox requests). 
- Survey spam: brand-new accounts whose first or only activity is survey-style questions (health/pharma surveys, product surveys) are Red — commercial data-harvesting spam. Observed pattern: a single GLP-1 survey-style question from a brand-new account.
- Thin identity + bait content: a thin-identity account (default avatar, no bio, no followers) that posts bait questions or bait posts is Red — the account exists to bait, not to participate. Volume doesn't matter. Reposted bait counts: reposting others' bait stories is bait content. Thin identity with zero content stays Yellow (dormant watch). Observed patterns: 1 bait question, bait posts, atheist-bait and Putin/nuclear fear-bait questions, duplicate "best president" bait questions, crude sexual bait post, reposted bait-style "girl" stories.
- Fabricated credentials + financial bait: fabricated employment/location credentials ("Manager at Investing", "Lives in Swizland") combined with crypto/financial bait content is Red — identity fraud in service of a financial scam. 
- Clearly inauthentic / bot behavior: mass near-identical answers or posts, copy-pasted content at scale, bulk-dumped generated content, inhuman output volume, engagement patterns inconsistent with a real person. This includes bot-cadence question spam: hundreds of formulaic questions posted minutes apart, nearly all unanswered. Observed pattern: 293 formulaic AGI-doom questions at machine cadence, fabricated "Cyber-Philosopher" persona vs "Cashier" credential, fake "Bulletin of Atomic Scientists 09.07.2026" citation. Observed pattern: the question-only farm node: 800 questions / 0 answers / 0 posts within weeks of account creation, common Western first+last name + default letter avatar + completely blank profile, follows each of its own questions immediately after posting, near-duplicate How/Why variants posted seconds apart, AI template openers ("Realistically, if...", "Can I realistically..."), hyper-precise decimals, long comma-separated noun lists, raw posts with missing-space tokenization artifacts ("andwildwindhorses") fixed by a self text-edit ~1 minute later, topic mix of false-premise paleontology + ethnicity bait + race/political bait + workplace-absurdity lists. Third Observed pattern: the template-permutation question farm: 573 questions / 0 answers / 0 posts, common Western first+last name + number suffix + default letter avatar + completely blank profile, follows each of its own questions immediately after posting, 2–3 locked question templates ("Do you agree with [time units] [listing]?", "What is the best part of [era] early/mid/late?") with numeric-range permutations reposted as near-duplicates (generations 1900–1919/1920–1939 reposted as 1907–1926/1927–1946, 1901–1920/1921–1940), false-premise bait questions, mechanical one-word signature tags ("Revolution"/"Dictator") appended to most questions — a generator-artifact tell, near-zero engagement. Any future profile matching most of these signals is Red on the pattern.
- AI-slop farming at scale: more than 5 long, maudlin/sentimental posts paired with AI-generated images. That's bot-like content farming — Red.
- Formulaic engagement-bait farming: high-volume posting of formulaic sentimental/engagement-bait content (templated emotional stories, bait questions, engagement-bait commenting, high-volume reposting) is Red even when the profile shows real identity signals (real photo, filled bio) — the farm pattern is in the content, not the identity. Observed patterns: 2.4K posts/879 answers of formulaic sentimental engagement bait since Oct 2024, low-effort one-liner content farm — 1.2K answers/1.4K posts, high-volume reposter, engagement-bait commenting.
- Content-farm operative: a profile embedded in content-farm Spaces — posting mass-produced trivia/sentimental AI-slop across unrelated topics, with fabricated formulaic credentials ("Heritage Researcher at X Research Centre", "Photographic Archivist at Kyoto Visual Heritage Center") that bear no relation to the claimed identity, at farm volume. 
- Sentimental farm-slop: a profile with fabricated farm-template credentials ("X Researcher/Analyst/Designer at Y Research Centre / Heritage Studio / Institute" style) posting sentimental/trivia/AI-slop content is Red regardless of volume — the credential fabrication is identity fraud and the content is inauthentic farm output. No post-count threshold applies; the ">5 long maudlin posts with AI images" rule above still covers non-farm-template cases on its own.
- Racist content: slurs, racial targeting, or sustained race-bait harassment is Red. This is not viewpoint — partisan commentary backed by real identity signals stays clear; racial abuse does not.
- Red-Space association: when assessing a new profile, check which Spaces its posts appear in. A profile whose posts concentrate in Red-listed Spaces is showing a strong Red indicator — it corroborates the content-farm operative verdict. One or two stray posts in a red-listed Space stays Yellow; a pattern of posting across red-listed Spaces points Red.
- Troll account (zero-history provocateur): a brand-new profile with no bio, no followers, no answers — nothing but provocative bait questions — is Red when the bait glorifies violent criminals, sexual predators, or similarly disturbing content. The zero-history pattern plus disturbing bait is the signature; volume doesn't matter because the account exists only to provoke. Troll-hunting space flags corroborate the verdict. Observed pattern: "serial killer friend" bait questions from a 0-follower, 0-answer throwaway.
- "Guys" — formulaic sockpuppet-troll archetypes; the defined types live in the companion file `quora_guys.md`. A profile matching most of any defined type's traits is an immediate Red — extract up to 100 of its followers first, assess each individually, then block the matches (subject to the block cap); do NOT expand to the followers' followers.
- Content-farm Space: when a Space matches the farm fingerprint (below), it triggers a sub-scan — assess the admin/moderator roster plus the most frequent recent posters (not every poster), then the Space itself goes on the Red Spaces list, is muted, and every operative assessed Red is added to the Red profile list and blocked. Red-listed Spaces are never visited again — no routine re-sweeps.
- Clearly disruptive: harassment, hate speech, threats, doxxing.
- Quora ban: a profile showing Quora's "This account has been banned" notice is Red on the ban alone — no further assessment needed. Attempt the block if the page offers a working Block action; banned pages usually don't, in which case the ban itself is the neutralization.
- Sexual abuse material: child sexual abuse material, or questions/content soliciting, describing, or eroticizing child sexual abuse, is Red on any instance. Violent sexual abuse material targeting adults (rape/sexual-violence content, sexual threats) is Red. Legitimate support, prevention, or legal discussion of abuse is NOT Red — the rule targets predatory/exploitative content. Assessors note the indicator without reproducing explicit material.
- Never Red on political viewpoint alone. Partisan commentary backed by real identity signals is not Red.
- When in doubt between Red and Yellow → Yellow.

- Industrial engagement-bait question farm with self-owned Space sink (added per Sulaksh investigation): a brand-new account producing thousands of items within weeks of creation (observed: ~1.5K answers + 700 questions + 780 posts in ~1 month), with questions posted minutes apart in bursts and locked to viral-prompt templates (emotional/confessional/nature-trivia bait — "What is the pettiest thing you have ever done after a breakup?", "What is one thing your grandmother did that you only understood years later?"). Identity tells: single first-name persona with no surname, non-photo avatar (cartoon/illustration), zero credentials filled in, near-zero social graph (single-digit followers, 0 following), and a self-owned Space administered by the account acting as the distribution sink where its posts concentrate. The verdict rests on the inauthentic operation — machine-cadence output, template-locked bait, manufactured persona — never on asking questions alone: a real person asking genuine varied questions stays clear.

- Sweet-persona engagement-farm node (added per Elana Oviedo investigation): a brand-new account built around a saccharine template persona — emoji-laden "simple woman with a loving heart" style bio, a thin single-claim credential (e.g. one job, no education/location), and burst posting across unrelated engagement themes (romance-fishing + partisan politics + saccharine intro post) within days of account creation. Tells: questions "followed" rather than asked — engagement farming instead of knowledge-seeking; amplification (follows and reshares) of other blocked slop accounts; a theme mix no genuine casual user produces in a burst. The verdict rests on the inauthentic operation — template persona, burst multi-theme bait, amplification network — never on political viewpoint or posting about dating: a real person writing genuine personal content stays clear.

Edit-log review (short-circuit rule): work identity → content in order and act as soon as a high-confidence verdict is determined — a settled Red is blocked and a settled Green is filed without opening the log. Open the log only when the verdict is still open or Yellow/doubtful, i.e. where it could change the outcome — EXCEPT for thin profiles (content-volume triage: fewer than 100 questions, answers, AND posts), where the log is checked FIRST because it carries the real activity signal. Abusive behavior in the edit history (harassment, hate, threats, vandalism) counts toward Red/Yellow the same as profile content.

- Follower sweep: when a profile is confirmed Red, open its followers list and collect the follower profile URLs before blocking. While collecting, note which follower entries have no Follow button — those profiles are already blocked: skip the block step for them if they assess Red (file as pre-existing block), but still assess them against the Red criteria and still sweep their followers. List-check them first (the seen-URLs record, red/yellow/green lists and archives — already-classified followers are skipped, never re-assessed), then collect-and-assess in one-visit browser tasks (~20 profiles per task): for each Red confirmed, collect the first 20 unclassified followers per Red (as listed on the followers page) and assess them against the Red criteria on the same visit. File the results, and then block — before extracting the next wave. Never extract more than 50 follower profiles ahead of the block portion: the sweep runs in waves (collect → assess → file → block → next wave), so unblocked Reds never pile up beyond 50. Each newly-confirmed Red from the sweep gets its own follower sweep. The sweep cascade ends after 5 waves regardless of blocks. Block cap — two tiers, 50 total per scan or directed-work session: tier 1 = 25 blocks WITH follower sweeps; tier 2 = 25 more blocks assess-and-block with NO follower sweeps and NO new waves. After 50 total blocks, delete any remaining queued profiles and close the scan — if the cap is reached, stop blocking and report the remainder to the operator.
- Assessment-only mode: when enabled, profile evaluation classifies each profile Red/Yellow/Green with the canonical procedure and files it in the lists, with no follower collection and no follower sweeps — the follower-sweep rule above is suspended while this mode is on. Reds are still blocked per the block rules (subject to the block cap, if one is in force). Applies to profile evaluation only. Toggle: `assessment_only_mode` in scan_settings.json.
- Report after block: after blocking a Red whose verdict matched the spam criterion or the child-sexual-abuse-material criterion, also report it to Quora. Report flow: open the profile's Report option → choose "Entire Profile" → choose "Spam" for spam verdicts or "Sexual exploitation of minors" for child sexual abuse material → select a minimum of 1 and a maximum of 3 items matching the criteria → wait a full 10 seconds after the selections visibly register (owner's fix: clicking Submit immediately fails with a generic Quora error) → Submit → move on to the next profile. Only profiles blocked during the current scan are reported — never pre-existing blocks, never banned accounts with no block action. If Quora shows a "you've reported too many times" (or similar rate-limit) error, stop all reporting immediately and pause the feature for 12 hours: record the pause in hidden_files/report_pause.json, and block-task briefs check it before attempting any reports (block-only while paused). If the Report flow opens but the item picker shows no selectable content (zero answers/posts and the offending items aren't listed — e.g. David-Walker-3480 on), log the outcome as "unreportable — no content" in hidden_files/quora_reports.json and move on: this is not a rate-limit and does not trigger a pause. Log every report outcome in hidden_files/quora_reports.json.

## 🟡 Yellow — watch

Probably disruptive, inauthentic, or spam — suspicious but not conclusive. Indicators:

- Thin identity: default letter avatar, no bio, no location, sparse profile, very new account, few or no followers, following nobody — especially combined with an engagement-bait pattern.
- Engagement bait: low-effort provocative questions or answers designed to farm outrage (repetitive blockade-style questions, short partisan one-liners at volume), rage-bait with no substantive content.
- Sockpuppet signals: name-plus-number clones of real users, inconsistent identity signals across profile and content.
- Viewpoint alone is never Yellow either. A real person with a real profile writing partisan commentary is clear, not Yellow.
- When uncertain → Yellow.
- Yellow is suspicion without proof: thin identity with zero content (dormant watch), or thin identity plus low-grade engagement patterns that match no Red rule. One concrete abusive act — impersonation, scam solicitation, threats — moves it to Red.
- Repetition is the throttle: high-volume repetition from otherwise real-looking accounts leans Red (bot-like behavior). Bait questions or bait posts from thin-identity accounts are Red regardless of volume (); thin identity with zero content stays Yellow. Exception: a zero-history troll account posting disturbing bait (glorifying violent criminals, sexual predators, etc.) is Red regardless of volume — see the Red rules.
- Content-farm Space activity: a profile posting in a farm-fingerprint Space (below) is suspicious. One or two stray posts with no farm-template credentials stays Yellow; fabricated farm-template credentials plus any farm slop is Red regardless of volume (sentimental farm-slop rule).

Content-farm Space fingerprint — the style of Space that triggers a sub-scan. A Space matches when it shows most of these: stated topic doesn't match the actual content (trivia, sentimental stories, celebrity gossip instead of the claimed subject); high post volume (~8–10+ posts per day for established farms; smaller/newer nodes may post less frequently — volume alone is not decisive); posts credited to formulaic fake personas with implausible "heritage researcher / research centre" credentials; inflated upvote counts on thin content; engagement bait mixed in. Two newer patterns (added per Curiosity Unlocked investigation): the curator-farm — an admin running multiple theme spaces whose activity is pure reshares/aggregation rather than authorship; and aggregation-farming — resharing old viral answers by unrelated established users instead of generating AI slop. Reuse of already-red-listed farm operatives as admins/mods is a strong corroborating signal. Two more patterns (added per Honey Bee's Dark Science investigation): the themed farm — the stated topic is genuinely present (e.g. paleontology imagery) but the operation is farm-like (hyper-volume, fake personas, no discussion); topic match alone does not clear a Space. And spiky engagement — most posts get 0–10 upvotes with occasional viral hits (1K+), consistent with algorithmic farming rather than organic community; steady moderate engagement is the legitimate pattern. One more pattern (added per Jon's political corner investigation): the political meme farm — partisan engagement-farming where the content stays on-topic (so no topic-mismatch signal) but the operation is farm-like: hyper-volume meme/share cadence (30+ posts/day), thin or fake poster personas (brand-new accounts bearing the Space's name, blocked hyper-prolific reposters), engagement-bait questions, and flat non-inflated engagement (0–1 upvotes per post). On-topic content does not clear a Space when the other farm signals are present. One more pattern (added per SharpenEdge investigation): the manufactured-persona ring — a Space whose admin/contributor roster is dominated by manufactured personas even when post volume is low and content stays on-topic. Tells: fabricated credentials (a degree listed as a school, e.g. "studied at Bachelor of Arts Degrees"), single-name thin identities, zero original answers/questions (pure reshare accounts), brand-new accounts already holding admin roles, and coordinated multi-Space admin patterns (same accounts co-admining the same pair of Spaces). A roster full of manufactured personas is itself a farm signal — the Space matches on this element alone when most of its operators show these tells, regardless of volume or topic fit. One more pattern (added per Real GangStalking Victims and Evidence investigation): the conspiracy-recruitment hub — a Space built around a conspiracy-victimhood identity (e.g. "Targeted Individual" / gangstalking lore) that functions as a recruitment and echo-chamber reinforcement network rather than a discussion or evidence venue. Tells: formulaic first-person testimony posts presented as "proof" while the Space claims to be an evidence repository; pseudo-documentary links framed as evidence (surveillance-tech news re-captioned as victim proof); explicit cross-space recruitment solicitations funneling members to sibling conspiracy Spaces; regional self-identification posts ("anyone targeted in NJ?") that map the audience for recruitment; author credential lines reading as invented victim identities ("Witness to digitalglobe using energy weapons on me", "Stalked by cult members"); an active echo-chamber commenter community (hundreds of comments on pinned posts) with no evidentiary standards. The verdict rests on the inauthentic operation — fabricated personas, recruitment funneling, evidence-claims without evidence — never on belief in the conspiracy alone: a genuine support community of real people discussing their experiences stays clear. A Space matching this pattern is Red-listed and muted; profiles whose posts concentrate there pick up the Red-Space association indicator, and formulaic operator personas are assessed Red on participation. One more pattern (added per Something Offensive Memes Space investigation): the meme-aggregator farm — the content stays on-topic (memes match the stated theme, so no topic-mismatch signal) but the operation is farm-like: hyper-volume meme cadence (50+ posts/day), burst posting by operators (multiple posts within a single hour), recycled image macros carrying external watermarks (aggregated, not original), joke or fabricated credentials on operator profiles, active recruitment funneling to an external site (tagline or links inviting members off-platform), ownership churn across successive owners, and a network of sibling/sister spaces. The verdict rests on the inauthentic operation — aggregation-farming, burst cadence, recruitment funneling — never on the humor being offensive: a genuine meme community of real people posting original or attributed content stays clear. A Space matching this pattern is Red-listed and muted; operator personas that are formulaic are assessed Red on participation. One more pattern (added per AU pair Nanny/Maid job Space investigation): the recruitment-scam funnel — a Space whose stated topic is job placement or recruitment (au pair, nanny, domestic staffing, visa-sponsored work) that functions as a funnel to off-platform scam contact rather than a job venue. Tells: posts routing applicants to a personal email address (Gmail rather than a company domain) or a Facebook/social profile under a mismatched third-party name (the named contact is not the poster and not an admin); urgency framing ("URGENT", "reply asap"); bundled implausible multi-role offers (au pair + nanny + maid + driver + chef + security + work-from-home in one post); US/Canada job offers pitched to international applicants, implying visa or work-permit sponsorship; CV harvesting via personal email; admins with fake or unrelated personas (a solar-panel trainer and a "computer analyst" running a nanny-recruitment space). Low post volume does not clear a Space when the funnel structure is present. The verdict rests on the inauthentic operation — fake personas, off-platform contact funnels under mismatched names, visa-framed lure offers — never on job postings alone: a genuine staffing agency or real family posting real jobs with verifiable contact details stays clear. A Space matching this pattern is Red-listed and muted; operator personas that are formulaic are assessed Red on participation. One more pattern (added per It's OK to be White investigation): the racial-grievance recruitment Space — a Space whose benign or cultural framing ("positivity", heritage celebration, "not a group for racists") masks sustained race-bait content: racial crime statistics aimed at one group, reparations-bashing, immigration fear-mongering, interracial-dating hostility, victimhood-narrative grievance — with virtually no actual cultural or heritage content. Tells: topic mismatch between the stated framing and the actual content; farm cadence (~9–10 posts/day); off-platform network links funneling members to Telegram/Gab/X groups; an operator roster dominated by thin or sockpuppet personas (ideological bios, joke or implausible credentials, minimal substantive posting history); reuse of already-Red fake personas as admins. The verdict rests on the inauthentic operation — masked framing, sockpuppet operators, off-platform funneling — plus the racist-content rule, never on cultural pride or identity discussion alone: a genuine ethnic or cultural community of real people sharing heritage, history, language, and traditions — without supremacist or race-bait content — stays clear. A Space matching this pattern is Red-listed and muted; operator personas that are formulaic are assessed Red on participation, operator profiles whose own content shows slurs, racial targeting, or sustained race-bait are assessed Red on their own behavior — and human-appearing operators are assessed on their own behavior and never blocked on association alone. One more pattern (added per The Real Q Mods investigation): the mission-masked dumping ground — a Space whose stated civic or activist mission (moderation watch, “looking out for each other,” community defense) masks industrial-scale off-mission content throughput. Tells: stark topic mismatch between the stated mission and the actual feed (partisan meme/shitpost churn filling a Space claiming moderation activism); hyper-volume cadence far beyond farm norms (observed: 200+ posts/day); a mass-manufactured moderator roster — hundreds of mods for a tiny follower base (observed: 219+ mods for 177 followers), sockpuppet-style joke identities (e.g. “MagaDevil,” “Satan-807,” “Temu McFreud Burger,” “Frmr Army Maj Nidal Hasan is a Republican Domestic Terrorist”), and duplicate roster entries from sloppy mass administration; inverted contributor/follower ratios (observed: 984 contributors vs 177 followers). The verdict rests on the inauthentic operation — mission-masking, manufactured administration, industrial throughput — never on the politics of the content: a genuine activist or moderation-watch community of real people posting on-mission content stays clear, however partisan its members. A Space matching this pattern is Red-listed and muted; operator personas that are formulaic are assessed Red on participation — and human-appearing operators are assessed on their own behavior and never blocked on association alone.

How it works: scans do not keep a standing sweep list. When a scan encounters an unclassified Space — via feed items, notification digests, or a profile whose posts concentrate there — it checks the Space against this fingerprint. On a match, run the sub-scan: assess the admin/moderator roster plus the most frequent recent posters (bounded, ~10), classify each by the Red/Yellow/Green rules above, then red-list the Space, mute it, and block the Red operatives. A Red-listed Space is excluded from all future visits — it is never swept again. Spaces already Red-listed are grandfathered as excluded.

## 🟢 Green — known good

Completely human, no further checks needed. A profile is Green when it shows all of:

- Real photo avatar, not a default letter.
- Filled-out identity: bio, location, and/or credentials (education, employment).
- Established history: joined a while ago, meaningful answer/question/post counts, a real follower base.
- Genuinely human content: original substantive answers, personal voice, varied topics, identity consistent across profile and content.
- No spam, bot, sockpuppet, or engagement-bait signals.

The account owner's follow is an automatic Green: if the owner follows the profile on Quora (profile page shows "Following"), it goes straight on the Green list with no assessment. The reverse carries no weight — a profile that follows the owner is assessed normally and can land on Red, Yellow, or Green.

Green profiles are recorded in the Green list and never loaded or checked again.

## 🟢 Green Spaces — never swept

A Space checked against the farm fingerprint and found to be a legitimate community goes on the Green Spaces list. Green Spaces are never visited or swept again, the same way Green profiles are never re-checked.

## 🔍 Source Spaces — swept for leads

Spaces whose posts flag or link to suspicious profiles (troll-hunting / alert spaces). Every scan sweeps each Source Space: collect the profile URLs of recent posters AND any profile URLs linked or flagged inside their posts, and add them to the candidate pool for Red/Yellow evaluation. A lead from a source space is assessed individually — an alert is a lead, not a verdict.

## Field notes

- The home feed is usually clean (mostly genuine authors). Reds surface through notifications, especially troll-alert spaces. Weight notification actors accordingly — the feed scan mostly confirms greens.
- Account age: very new (joined within weeks) plus bait/troll behavior is a strong red/yellow signal; number-suffixed throwaway usernames add to it. But an aged account is not a pass — behavior decides.
- Troll-hunting spaces over-flag. A space alert is a lead, not a verdict — always assess individually. Viewpoint-only profiles caught in alerts are clear.
